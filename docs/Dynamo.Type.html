        Behaviour for schema field types.

        A type converts between an Elixir value and a DynamoDB attribute value (%{"S" => "..."}, %{"N" => "1"}, …).

        defmodule MyApp.Type.Money do
  use Dynamo.Type

  def dump(%Money{} = m), do: {:ok, %{"N" => Money.to_string(m)}}
  def dump(_), do: :error

  def load(%{"N" => n}), do: {:ok, Money.parse!(n)}
  def load(_), do: :error
end

        nil is handled uniformly: it dumps to %{"NULL" => true} and loads back to nil for every type. Fields that are nil are omitted from written items by default (see Dynamo.Schema).

        cast(term)

        Casts loosely typed input (e.g. from params) into the Elixir value. Optional.

        dump(term)

        Converts an Elixir value into a DynamoDB attribute value.

        load(dynamo_value)

        Converts a DynamoDB attribute value back into an Elixir value.

        Functions

        builtin()

        Returns the list of built-in type atoms.

        dump(type, value)

        Dumps a value with the given type. nil always becomes NULL.

        dump!(type, value, field \\ "value")

        Dumps a value or raises ArgumentError with an actionable message.

        load(type, value)

        Loads a DynamoDB attribute value with the given type. NULL always becomes nil.

        load!(type, value, field \\ "value")

        Loads or raises.

        resolve!(type)

        Resolves a type spec (builtin atom or module) to a module implementing Dynamo.Type. Raises ArgumentError for unknown types.
