        Modules

        Dynamo.Client

        Low-level DynamoDB HTTP client: SigV4 signing, retries with jittered exponential backoff, error normalisation and telemetry.

        Dynamo.Condition

        Builds ConditionExpression / FilterExpression strings from Elixir terms, generating attribute-name and value placeholders so you never write names:/values: by hand.

        Dynamo.Credentials

        AWS credential resolution.

        Dynamo.Credentials.Cache

        Long-lived owner of resolved credentials for a repo. Started by the repo supervisor.

        Dynamo.Encodable

        Protocol used by the :any type (and nested :map/:list values) to encode structs and custom values that have no explicit field type.

        Dynamo.Error

        The single error type returned by every Dynamo operation.

        Dynamo.Key

        A resolved DynamoDB primary key for a table or index.

        Dynamo.Page

        A page of results from query/scan.

        Dynamo.Raw

        Wraps a value that is already in DynamoDB attribute-value format so the encoder passes it through untouched.

        Dynamo.Repo

        Defines a repository: a supervised process tree that owns the DynamoDB client (region, endpoint, credentials, retry policy) and exposes the operations.

        Dynamo.Request

        Pure builders for DynamoDB request payloads.

        Dynamo.Schema

        Defines a DynamoDB item schema with typed fields, keys and indexes.

        Dynamo.Stream

        Lazy streams over paginated Query/Scan results.

        Dynamo.Type

        Behaviour for schema field types.

        Dynamo.Type.Any

        :any – type inferred from the Elixir value on dump and from the DynamoDB tag on load. Uses the Dynamo.Encodable protocol for structs and custom values. Use an explicit type when you can; :any cannot round-trip atoms, dates or decimals, and always loads numbers as integers/floats.

        Dynamo.Type.Binary

        :binary – B (base64 on the wire). Never inferred; always explicit.

        Dynamo.Type.BinarySet

        :binary_set – BS (base64 on the wire). Empty sets dump to NULL.

        Dynamo.Type.Boolean

        :boolean – BOOL.

        Dynamo.Type.Date

        :date – S ISO 8601 date.

        Dynamo.Type.Decimal

        :decimal – N, using the optional decimal dependency for exact arbitrary-precision numbers (the correct choice for money).

        Dynamo.Type.Float

        :float – N. Integers are accepted on dump.

        Dynamo.Type.Integer

        :integer – N.

        Dynamo.Type.List

        :list – L. Elements are encoded with Dynamo.Type.Any.

        Dynamo.Type.Map

        :map – M. Values are encoded with Dynamo.Type.Any (inferred). Keys are converted to strings on dump and stay strings on load.

        Dynamo.Type.NaiveDateTime

        :naive_datetime – S ISO 8601 without offset.

        Dynamo.Type.NumberSet

        :number_set – NS. Empty sets dump to NULL.

        Dynamo.Type.String

        :string – S. Atoms (other than booleans/nil) are accepted on dump and become strings.

        Dynamo.Type.StringSet

        :string_set – SS. Empty sets dump to NULL (DynamoDB rejects empty sets).

        Dynamo.Type.Time

        :time – S ISO 8601 time.

        Dynamo.Type.TypedList

        {:list, type} – L whose elements are all dumped/loaded with type. Resolved by Dynamo.Type.resolve!/1; not used directly.

        Dynamo.Type.UTCDateTime

        :utc_datetime – S ISO 8601 with Z. Stored in UTC; sorts lexicographically.

        Dynamo.Type.Vector

        :vector / {:vector, dimensions} – a list of floats stored as L of N, the format DynamoDB vector indexes expect. With a dimension the length is checked on dump and load.

        Dynamo.Update

        Builds DynamoDB UpdateExpressions from a keyword list or map of changes.

        Mix Tasks

        mix dynamo.create_table

        Creates a DynamoDB table and waits until it is ACTIVE.

        mix dynamo.delete_table

        Deletes a DynamoDB table after confirmation.

        mix dynamo.generate_schema

        Inspects a table (key schema, GSIs and a sample of items) and writes a schema module that can read the existing items back.

        mix dynamo.list_tables

        Lists tables, following pagination.
